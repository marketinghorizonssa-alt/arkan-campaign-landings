هل أركان بنك أو جهة تمنح تمويلًا؟+

أركان التنفيذية تقدم حلولًا واستشارات مالية وعقارية، وليست بنكًا ولا تمنح قرضًا مباشرًا.

هل التقييم الأولي مجاني؟+

نعم، تقييم البيانات الأساسية أوليًا مجاني. وعند الحاجة لخدمة إضافية، يوضح لك الفريق تفاصيلها وأي رسوم قبل اتخاذ القرار.

هل يمكن ضمان قبول التمويل؟+

لا يمكن ضمان الموافقة. القرار والشروط تحددهما الجهات الممولة وفق بيانات كل حالة.

وش يحدث بعد إرسال طلبي؟+

يتواصل فريق أركان لفهم احتياجك، ويطلب المعلومات الإضافية اللازمة ويوضح الخطوة التالية.

هل الالتزامات تمنع التمويل العقاري دائمًا؟+

أثر الالتزامات يختلف حسب الدخل ونسبة الاستقطاع ونوع التمويل ومتطلبات الجهة. لذلك نبدأ بمراجعة تفاصيل حالتك.
